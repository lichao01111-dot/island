# 小岛生存 · 卡通

一个低多边形风格的岛屿生存/经营沙盒游戏。你在自己的小岛上采集、建造、熬过昼夜与野猪，出海远征带回稀有材料与图纸，再把岛屿发布成短链接，让朋友来参观、留言、留伴手礼。

- 技术栈：TypeScript + [Three.js](https://threejs.org/)（低多边形 + 顶点色 + 平面着色）
- 构建：esbuild
- 服务端：零依赖 Node.js（只用内置 `node:http`），负责短链与访问计数
- 平台：桌面（键鼠）+ 手机/平板（虚拟摇杆 + 点按）

## 玩法

一个 5 分钟一天的小型生存循环，三层递进：

1. **活下来**：采集椰子、木材、纤维、石料，管理生命/饥饿/口渴/体力。夜晚会变冷、会有野猪出没——篝火和灯塔能驱赶它们。
2. **建起来**：篝火、庇护所、集雨器解决温饱；码头 + 制图桌打开远征。建筑还有位置约束（码头必须贴水线、灯塔必须建在高处），选址本身就是决策。
3. **走出去**：远征群岛带回稀有材料与升级图纸，反哺主岛；漂流物会漂到岸边可打捞；住客会漂来并安家、持续产出与提要求。

### 主要系统

| 系统 | 说明 |
|---|---|
| 采集 | 椰子树 / 灌木 / 石堆，会重生；花圃自己长果子 |
| 生存数值 | 生命、饥饿、口渴、体力；昏倒会回营地，不惩罚存档 |
| 昼夜与天气 | 5 分钟一天，午后阵雨给集雨器补水 |
| 建筑 | 7 种 + 远征图纸升级；灯塔大范围照明驱兽 |
| 野猪 | 夜晚出没，会蓄力冲撞，篝火/灯塔范围内安全 |
| 漂流物 | 海上漂来、靠岸后可打捞 |
| 远征 | 3 座岛（红树林 / 礁石 / 洞穴）、有限载货、探索点与图纸；野兽（礁蟹）是探索的阻力 |
| 住客 | 有人漂到码头，盖小屋让他安家，每天产出、定期提要求（见 [RESIDENTS.md](RESIDENTS.md)） |
| 分享与参观 | 岛屿打包成短码发布，朋友可参观、留言、留伴手礼；待客清单决定岛屿等级 |

## 操作

### 桌面（键鼠）

| 按键 | 功能 |
|---|---|
| `W` `A` `S` `D` / 方向键 | 移动 |
| `E` / `空格` | 互动（采集、打捞、饮水、调查、对话） |
| `F` | 进食 |
| `Q` | 给篝火加柴 |
| `R` | 烤椰子 |
| `U` | 升级附近建筑 |
| `M` | 打开航海图 |
| `V` | 切换俯视 / 越肩视角 |
| `1`–`6` | 建造对应建筑 |
| `C` | 切换角色模型 |

### 手机 / 平板

- **左半屏拖动**：虚拟摇杆移动
- **右半屏点按**：互动
- **底部物资格 / 右下按钮**：进食、建造、篝火操作、升级

> 自动识别触屏设备并显示触屏提示；HUD 与浮层按刘海安全区（`safe-area-inset`）偏移，横竖屏切换会重新适配。

## 运行

要求：Node.js 18+。

```bash
npm install

# 开发模式：短链服务 + 静态站点，并监听 src/ 自动重新打包
npm run dev
# 打开 http://localhost:8003

# 生产模式：起服务，不做源码监听
npm start

# 纯静态（不跑短链服务，用 esbuild serve + watch）
npm run dev:static
# 打开 http://localhost:8002

# 一次性构建 web/main.js
npm run build

# 测试与类型检查
npm test
npm run typecheck
```

环境变量：`PORT`（服务端口，默认 8003）、`HOST`（默认 0.0.0.0）、`ISLAND_DATA`（短链数据文件路径，默认 `data/islands.json`）。

> 不跑服务也能玩、也能用长码分享；服务端只额外提供短链与访问计数，并且刻意不理解游戏规则（只做结构校验）。

## 短链服务 API

零依赖的 Node 服务，把长长的岛屿码换成 6 位短 id，并记录到访、留言、伴手礼：

| 方法 | 路径 | 说明 |
|---|---|---|
| `POST` | `/api/islands` | 发布岛屿，返回短 id + 岛主令牌 |
| `GET` | `/api/islands/:id` | 取回一座岛（不含令牌） |
| `POST` | `/api/islands/:id/visits` | 记一次到访 |
| `POST` | `/api/islands/:id/messages` | 留言 |
| `POST` | `/api/islands/:id/gifts` | 留一件伴手礼 |
| `DELETE` | `/api/islands/:id/gifts` | 岛主凭令牌领取礼物 |
| `DELETE` | `/api/islands/:id/messages/:idx` | 岛主凭令牌删除留言 |

存储是一个 JSON 文件，写入走「临时文件 + rename」，避免进程中断留下半个坏文件。

## 项目结构

```
src/
  main.ts                入口：场景、昼夜、数值、采集/建造/远征接线
  game/                  玩家、输入、HUD、存档、分享、材质、后期
  world/                 岛屿地形、建筑、资源、野猪、漂流物、远征、住客、野兽
  platform/              存储适配、触屏与安全区检测
server.mjs               零依赖短链服务 + 静态站点
build.mjs                esbuild 构建/监听脚本
web/                     静态入口（index.html + 资产）
test/                    纯逻辑测试（Node 直接跑，无需浏览器）
tools/                   资产导出/检查、截图脚本
```

架构上几个刻意保持的边界：

- **资产可选**：每件外部 GLB 都有程序化几何体回退，文件缺失也能玩（见 [ASSETS.md](ASSETS.md)）。
- **服务端不懂游戏规则**：只做结构校验，岛屿码合法性由客户端解码时判断。
- **纯逻辑与视图分离**：`beasts.ts` / `residents.ts` 不 import THREE，便于在 Node 里直接测试。
